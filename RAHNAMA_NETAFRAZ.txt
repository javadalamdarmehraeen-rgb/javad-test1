راهنمای نت‌افراز + Render — نسخه ۱۱.۹۷.۰
========================================

هدف: برنامه روی نت‌افراز جدا کار کند (حتی اگر Render در ایران قطع باشد).
اگر کاربر چیزی ثبت کرد، وقتی شبکه اجازه دهد همان داده به Render هم می‌رود و برعکس.

الف) نت‌افراز (mehraeinpharma.ir / ndcohub.ir)
1. در VS Code:
     npm run build-static
   اگر همگام با Render هم می‌خواهید:
     set BASE_URL=https://javad-test1.onrender.com
     npm run build-static
2. تمام محتویات پوشه static-build را در public_html آپلود کنید.
   حتماً این‌ها باشند: leaflet.css, leaflet.js, images/, api.php, .htaccess, crm-app.js
3. در پنل نت‌افراز:
   - SSL / Let's Encrypt را روشن کنید (https بدون خطا).
   - PHP 7.4+ فعال باشد.
   - mod_rewrite معمولاً روشن است.
4. تست: https://mehraeinpharma.ir/login.html سپس ورود.
   /api/health باید JSON برگرداند نه ۴۰۴.

ب) Render
- مثل قبل: npm start و PLATFORM=fullstack
- دامنه نت‌افراز در CORS از قبل مجاز است.

ج) چرا اطلاعات قدیمی می‌ماند؟
آپلود فایل جدید، حافظه مرورگر همان دامنه را پاک نمی‌کند.
داده نت‌افراز در crm-netafraz-data.json روی هاست و در localStorage مرورگر است.
نمونه قدیمی (ph-1 و مشابه) حذف می‌شود؛ داروخانه واقعی شما پاک نمی‌شود.

د) خطای گواهی Service Worker
تا SSL نت‌افراز درست نشود، PWA ثبت نمی‌شود. خود برنامه بدون آن کار می‌کند.
ه) نسخه کنار لوگو باید با کادر ورود یکی باشد (۱۱.۹۵.۰). اگر ۹۱ می‌بینید کش را خالی کنید.

و) داده قدیمی از کجا می‌آید؟
- localStorage همین دامنه (آپلود فایل آن را پاک نمی‌کند)
- فایل crm-netafraz-data.json روی هاست نت‌افراز
- تا ۱۱.۹۴ اگر API نت‌افراز ۴۰۴ می‌داد، برنامه ممکن بود داده رندر را بنشاند. از ۱۱.۹۵ این کار فقط با BASE_URL صریح است.

اگر می‌خواهید نت‌افراز خالی باشد:
1. در مرورگر برای mehraeinpharma.ir داده سایت را پاک کنید، یا از تب عیب‌یابی با حساب مدیر «شروع تازه فقط روی این دامنه» را بزنید.
2. روی هاست فایل crm-netafraz-data.json را حذف کنید (اگر وجود دارد).
داروخانه واقعی شما را برنامه خودش خالی نمی‌کند.

ز) همگام نت‌افراز → رندر (نسخه ۱۱.۹۷.۰)
1. در VS Code قبل از ساخت:
     set BASE_URL=https://javad-test1.onrender.com
     npm run build-static
   سپس کل static-build را آپلود کنید (api.php و api-config.php حتماً باشند).
2. تست دستی در مرورگر:
     https://mehraeinpharma.ir/api/sync?target=render
   باید JSON با status=success برگردد نه ۴۰۴.
3. اگر baseUrl خالی باشد، api.php خودش به https://javad-test1.onrender.com می‌فرستد (فقط ارسال؛ کشیدن خودکار فقط با BASE_URL).
4. هر ذخیره روی نت‌افراز همان لحظه به رندر push می‌شود. اگر رندر قطع باشد، داده محلی می‌ماند و خطا در JSON می‌آید.
5. ذخیره خالی داروخانه‌ها به رندر فرستاده نمی‌شود.

ح) یکی بودن داده رندر و نت‌افراز (۱۱.۹۷.۰)
فقط npm run build-static کافی است — BASE_URL پیش‌فرض رندر است.
بعد از آپلود، اولین ورود نت‌افراز داده را از رندر می‌گیرد و حافظه قدیمی همان دامنه را کنار می‌گذارد.
اگر رندر خالی باشد یا قطع باشد، داروخانه‌های نت‌افراز پاک نمی‌شوند.
